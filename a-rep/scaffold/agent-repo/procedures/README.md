# procedures

Trusted, reviewed ways of working.

Material belongs here only after the V1 promotion rule has been satisfied:

`experience -> scratch -> proposal -> review -> human approval -> procedures`

Use the provided subdirectories for SOPs, tested scripts, approved reusable skills, and formal graph/process descriptions.

For skills specifically, experimental capability packages live in `scratch/skills/`; approved durable capability packages live in `procedures/skills/` only after explicit human approval.

Procedures and approved skills describe trusted ways/capabilities. They do not manufacture authority for consequential actions.
