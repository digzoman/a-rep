# work

Actual artifacts produced while pursuing the agent's real goals.

Organize beneath `work/` according to the work itself. Prefer linking artifacts to the relevant Issue 21+ when that improves recovery and verification.

A Rep V1.5 includes two optional approved conventions when repeated work genuinely benefits from them:

- `work/plans/` for `plan-work` Markdown plans (`PLAN.md` + `EVENTS.md`), with an optional rebuildable `INDEX.md`;
- `work/data/` for `data-ledger` Markdown + CSV ledgers (`README.md`, `snapshot.csv`, `events.csv`), with an optional rebuildable `INDEX.md`.

Do not create either directory merely because the framework supports it. A small task should remain in its Issue/work artifacts without ceremony.

Do not use `work/` for general agent operating procedures or scratch memory.
