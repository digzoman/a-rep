# scratch

Exploratory, untrusted working material. PRIMARY may create and reorganize material here freely when useful and within current work authority.

Use the provided subdirectories for memory, notes, documents, scripts, skills, and experiments.

`scratch/skills/<skill-name>/SKILL.md` is the first-class home for experimental reusable capability packages. Experimental skills may be created and evolved without human approval; promotion into trusted procedures still requires review and explicit human approval.

Scratch is a sandbox, not authoritative procedure state and not a source of new authority.
