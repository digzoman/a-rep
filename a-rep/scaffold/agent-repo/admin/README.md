# admin

Durable operational information about the agent itself belongs here.

Use `admin/logs/` for concise sanitized Git-visible cycle logs and `admin/runtime/` for runtime installation, scheduler, verification, and recovery documentation.

Executed-cycle logs should carry producer provenance and `Agent-Run` when available so records from multiple shared-account agent surfaces remain distinguishable and correlatable.

Do not put raw coding-agent transcripts or secrets here.
