# A Rep scaffolds

`agent-repo/` is the canonical V1.2 filesystem scaffold for a private persistent-agent repository.

New agents should be bootstrapped from this structure. Existing agents should be patched conservatively, preserving agent-specific work, procedures, scratch material, configuration, and live operational state.

The scaffold is intentionally structural rather than application-specific. It defines where categories of material belong and includes standardized hot/deep strategic context files without prescribing the content of real work.
